## Doel

Multi-tenant authentication and authorization: Supabase Auth-backed login,
tenant provisioning (creating a new company's tenant + admin role +
workflow steps atomically), and per-tenant configurable roles/permissions
baked into each user's JWT `app_metadata`. Includes the admin UI for
inviting users and managing roles.
